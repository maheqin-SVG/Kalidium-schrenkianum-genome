# LTR-RT insertion time analysis

This directory contains the scripts used to estimate and visualize the insertion times of LTR retrotransposons (LTR-RTs) in the *Kalidium schrenkianum* genome.

## Directory structure

- `1.LTR_identity_extraction.sh` — extraction of LTR sequence identity for intact LTR-RTs
- `2.LTR_insertion_time_plot.R` — calculation and visualization of LTR-RT insertion times
