# Genome synteny analysis

This directory contains the scripts used for comparative synteny analysis among *Kalidium schrenkianum*, *Halogeton arachnoideus*, and *Beta vulgaris*.

### `001.MCScanX`

Identification of collinear blocks using MCScanX:

- `MCScanX.analysis.sh` — all-vs-all BLASTP and MCScanX-based collinearity analysis

### `002.JCVI`

Pairwise synteny analysis and chromosome-level visualization using JCVI:

- `JCVI.Synteny_analysis.sh` — identification and filtering of pairwise syntenic blocks and chromosome-level synteny visualization
